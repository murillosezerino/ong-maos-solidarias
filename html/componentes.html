Guia de componentes

Referência visual dos componentes de feedback e das classes que devem ser usadas no front-end e no back-end.

Badges

Etiquetas curtas para classificar projetos e campanhas. Classe base .badge com um modificador.

  • Informativo
  • Em andamento
  • Vagas limitadas
  • Urgente
  • Encerrado

Alertas

Mensagens fixas na página. Classe base .alerta com um modificador. Use role="alert" apenas em erros que aparecem após uma ação.

Informação: o cadastro leva cerca de 3 minutos.

Tudo certo: seu cadastro foi recebido.

Atenção: faltam 180 cestas para atingir a meta.

Erro: não foi possível enviar o formulário. Tente novamente.

Toasts

Notificações temporárias que não bloqueiam a página. Chame mostrarToast(mensagem, tipo) no JavaScript.

Modal

Janela de confirmação feita com o elemento nativo <dialog>. Abra com data-abre-modal e feche com data-fecha-modal ou Esc.
